=== WHAT IS CODETUTOR? ===

CodeTutor is an AI-powered Java learning platform designed for university students. It combines multiple learning pathways, an intelligent AI tutor, interactive code editors, quizzes, coding challenges, and comprehensive classroom management. The platform guides students step-by-step through Java programming from beginner to advanced level, with flexibility to choose their preferred learning track.

=== QUICK START: CHOOSE YOUR LEARNING PATH ===

When you first log in to CodeTutor, you'll be asked to choose a learning path:

**Basic Java (Recommended for beginners)**
- 12 main topic groups covering foundational to advanced Java concepts
- Prerequisite-based unlocking (complete each group before moving to the next)
- Traditional step-by-step learning progression
- Best for: Students new to Java or those who prefer a structured, guided approach

**Enhanced Java (For advanced or fast-track learners)**
- 8 main topic groups with condensed, practical focus
- Faster-paced content with more direct application to real-world scenarios
- Reduced prerequisites for faster progression
- Best for: Students with programming experience or those who want to accelerate their learning

You can switch between paths anytime from the "Home" menu or by visiting the Course Catalog page.

Your progress is tracked separately for each path — switching paths doesn't erase your previous work.

Each path includes the same powerful tools: AI tutor, code editor, quizzes, challenges, and classroom integration.

=== LEARNING ROADMAP (BASIC PATH) ===

The homepage shows your chosen Learning Roadmap — a visual interactive map organized into topic groups. In the Basic Java path, you'll see 52 subtopics organised into 12 main topic groups that must be completed in order to ensure prerequisite knowledge is built up progressively.

The 12 topic groups in the Basic path (in order) are:
1. Bridging from Python — syntax differences, type system, compilation, program structure
2. Problem Solving with Java — algorithm thinking, code optimisation, pseudocode, debugging
3. String — string operations, formatting, parsing, StringBuffer/StringBuilder
4. Array — declaration, traversal, multi-dimensional, utility methods
5. Methods — defining, calling, parameters, return values, overloading, recursion
6. Exception Handling and File IO — try/catch/finally, custom exceptions, file read/write
7. Class (constructor, attributes, methods) — OOP fundamentals, constructors, encapsulation
8. Class (access modifier, static) — public/private/protected, static variables and methods
9. Inheritance — extends keyword, method overriding, super keyword, class hierarchy
10. Polymorphism — runtime polymorphism, upcasting, downcasting, instanceof
11. Interface and Lambda Expression — interface definition, implementing interfaces, lambda syntax, functional interfaces
12. Recursion and Revision — recursive algorithms, base cases, comprehensive review

To mark a topic as complete, open the topic page and click the "Mark as Complete" button. A green tick will appear on the roadmap node.

=== LEARNING ROADMAP (ENHANCED PATH) ===

The Enhanced Java path is designed for students with programming experience or those who want a faster-paced learning track. It contains 26 subtopics organized into 8 main advanced topic groups that must also be completed in order.

The 8 topic groups in the Enhanced path (in order) are:
1. Advanced OOP — abstract classes, interface design patterns, generics and type parameters
2. Collections Framework — List, Map, Set, and Queue implementations, choosing the right collection type
3. Streams & Functional Programming — Stream API, lambda expressions, functional interfaces, method references
4. Exception Handling & File I/O — checked vs unchecked exceptions, custom exceptions, file operations, streams
5. Concurrency — threads, synchronization, thread lifecycle, concurrent utilities
6. Data Structures — arrays, lists, stacks, queues, trees, hashing concepts
7. Algorithms — sorting, searching, complexity analysis, optimization techniques
8. Advanced Patterns — recursion optimization, design patterns, problem-solving strategies

Like the Basic path, marking topics complete unlocks the next group. The Enhanced path assumes you already understand Java fundamentals (classes, methods, basic OOP) and focuses on advanced professional-level concepts.

**Switching Between Paths:**
If you started with Basic Java but want to switch to Enhanced Java (or vice versa), you can change your path anytime. Your progress in each path is tracked separately.

=== HOW TO NAVIGATE TOPICS ===

Click any unlocked node on the roadmap to open its topic page. Each topic page shows:
- A description of the topic
- Learning resources (links to W3Schools, GeeksForGeeks, Oracle, and textbook chapters)
- Reference documents from the knowledge base
- Previous / Next navigation buttons to move sequentially through subtopics
- A "Mark as Complete" button to record your progress

=== AI TUTOR (ASK AI BUTTON) ===

Click the "☕ Ask AI" button at the bottom-right of any page to open the AI tutor chat panel. The AI is powered by a RAG (Retrieval-Augmented Generation) system backed by over 2000 Java knowledge chunks from W3Schools, Oracle documentation, GeeksForGeeks, and textbooks including Think Java and Java Notes.

How to use the AI Tutor:
- Type any Java programming question into the text box and press Enter or click Send.
- The AI searches the knowledge base for relevant passages and generates a grounded answer.
- Use Shift+Enter for multi-line questions.
- Sources (📚 Sources) are shown below each answer — click to expand a source and see the retrieved paragraph.
- Click "🔍 Show Context" on a source to see the surrounding chunks for deeper context.
- Click "Expand" (top-right of the panel) to open the full Conversation History page.
- Click "History" (top-left of panel) to see and reload previous chat sessions.
- Click "New Chat" to start a fresh conversation.

Knowledge source selection:
At the bottom of the chat panel, you can choose which knowledge sources the AI should search. "General Java KB" uses the main Java knowledge base. If you are enrolled in a classroom, you can also toggle classroom-specific documents uploaded by your teacher.

The AI tutor initialises lazily on first use — if you see "Initializing AI tutor… first load may take 30s", please wait for it to warm up before sending questions.

=== QUIZ FEATURE ===

Quizzes on CodeTutor test your understanding of Java topics through multiple-choice questions. The quiz feature is a built-in learning assessment tool on the platform — not a Java language concept.

To take a quiz:
1. Navigate to a topic page and click "Take Quiz" or go to the Exercises page from the sidebar (📝 Exercises).
2. Select the Java topics you want to be tested on.
3. Choose the number of questions (5, 10, or 15).
4. Answer each multiple-choice question.
5. After submission, your score is shown with correct/incorrect answers and explanations.

Pass criteria: A score of 70% or above counts as a passing session.
Progress: Passed quiz topics count toward your overall progress score.
Results are saved to "My Work" automatically.
You can re-attempt quizzes as many times as you want to improve your score.

Teachers can also auto-generate quizzes directly from classroom-uploaded materials using the "Generate Quiz from Materials" button in the Teacher Dashboard.

=== CODING CHALLENGES (PRACTICAL TESTS) ===

Coding Challenges test your ability to write complete Java programs. To take a challenge:
1. Navigate to the Coding Challenges page from the sidebar (🎯 Coding Challenges).
2. A problem specification is shown — read it carefully.
3. Write your Java solution in the built-in editor.
4. Click "Submit" to run automated test cases against your solution.
5. You receive a score based on how many test cases pass.

Pass criteria: A score of 60% or above counts as passing.
Hints are available if you get stuck — a limited number of hints are provided per challenge.
Results are saved to "My Work" automatically.

=== CODE PLAYGROUND (LIGHTWEIGHT EDITOR) ===

The Code Playground (accessible from the left sidebar: 💻 Playground) provides a quick, lightweight Monaco-based code editor with Java syntax highlighting. Perfect for quick experiments and learning code snippets.

Features:
- Write and run small Java code snippets quickly
- Syntax highlighting for Java code
- Code execution powered by Paiza API
- Standard input/output support
- Auto-saved per topic — persists across page reloads
- "Save to My Work" button to permanently save snippets with a custom name
- Error output displayed in a compiler tab
- "Explain Error" AI button appears when errors occur — click to get a plain-English explanation powered by the AI tutor

Typical use: Quick testing, learning single concepts, experimenting with code syntax.

=== FULL IDE (COMPILER) ===

In addition to the lightweight playground, CodeTutor includes a full-featured Integrated Development Environment (Full IDE/Compiler) for more comprehensive Java development. Access it from the main navigation or link on lesson pages.

Full IDE Features:
- Complete Monaco editor with advanced syntax highlighting and auto-completion
- Multi-file project support (organize code into multiple files)
- Real-time Java compilation and execution
- Integrated console with standard input/output support
- Debugging capabilities and enhanced error messages
- Advanced code organization and project management
- "Run" button to execute your complete Java program
- Compiler tab showing detailed compilation errors and runtime output
- "Explain Error" AI button for error clarification
- Full-featured development environment for complex programs

Typical use: Building complete Java applications, multi-file projects, testing larger programs, solving Practical Test challenges.

=== WHEN TO USE PLAYGROUND VS IDE ===

- **Use Playground** for: Quick snippets, learning syntax, experimenting with small code pieces, testing a single concept during a lesson
- **Use Full IDE** for: Complete programs, multi-file projects, Practical Test challenges, larger applications, complex debugging

=== PROGRESS TRACKING ===

Click the circular progress indicator in the top navigation bar (shows a percentage like "39%") to open the Learning Progress modal.

The modal shows:
- Weak Areas: Topics where your average quiz/test score is below 70% — shown at the top to highlight what needs attention.
- Overall Progress: Combined score out of total (roadmap completions + quiz passes + test passes).
- Learning Roadmap: How many of the 52 subtopics you have marked complete.
- Exercises: How many quiz topic groups you have passed (pass score ≥70%).
- Coding Challenges: How many coding challenge topic groups you have passed (pass score ≥60%).
- Code Playground: Number of code executions completed.
- AI Tutor Interactions: Number of questions asked to the AI.

Progress is tracked locally (localStorage) and synced to the server when logged in.

=== MY WORK PAGE ===

The My Work page (accessible from the sidebar: 📁 My Work) stores all your saved work:
- 💻 Code — playground code snippets you saved
- 📝 Quiz — quiz results with scores and answers
- 🧪 Test — coding challenge submissions with scores

You can filter by type using the buttons at the top. Click on any item to expand and see your full answers and score. You can also delete individual work records.

=== CHAT HISTORY ===

The Chat History page (accessible by clicking "Expand" in the AI chat panel, or from the sidebar: 🕘 Chat History) shows all previous AI tutor conversations.

Each conversation entry shows the first message title and can be re-opened to continue a session. You can also delete old conversations.

=== CLASSROOMS (FOR ENROLLED STUDENTS) ===

Classrooms allow you to learn in a structured group environment with teacher-provided materials and guidance. Your teacher can create a classroom and send you a class code to join.

**Joining a Classroom**
To join a classroom on CodeTutor:
1. Navigate to the My Classrooms page from the left sidebar (🎓 My Classrooms).
2. Click "Join a Classroom".
3. Enter the class code provided by your teacher.
4. Click "Join" — you're now enrolled!

Class codes are case-sensitive. If the code is expired or invalid, ask your teacher to generate a new one.

**Classroom Features**

**1. Course Materials & Documents**
Your teacher can upload course-specific documents (PDFs, notes, guides) to the classroom. To access them:
- Open the Classrooms page and select your classroom
- Browse all uploaded materials in the "Materials" or "Documents" section
- Click on any document to view it
- Materials are organized into sections/folders for easy navigation
- The platform tracks your reading progress — documents show whether you've finished reading them

**2. Material Read Tracking**
To mark a document as read:
- Open a document in the classroom
- Scroll through and review the content
- Click "Mark as Complete" or "Mark as Read" to record that you've finished
- Your reading progress appears in the classroom dashboard (shows % of materials reviewed)
- Teachers can see which students have reviewed which materials

**3. Classroom-Specific AI Tutor**
When you ask the ☕ Ask AI tutor questions while in a classroom, you can toggle "Classroom Mode" to have the AI search your teacher's uploaded materials first:
- Open the AI chat panel (☕ Ask AI)
- At the bottom, you'll see a toggle for your classroom name
- Enable "Classroom Mode" to search classroom materials
- The AI will answer using your teacher's materials plus the general Java knowledge base
- Perfect for questions specific to your course's approach or materials

**4. Classroom Quizzes**
Your teacher can generate quizzes directly from classroom materials:
- Navigate to the Quizzes section of your classroom
- Your teacher may have auto-generated quizzes from the course materials
- Click "Take Quiz" to start
- Answer questions designed to test your understanding of the classroom content
- Your scores are tracked and visible to your teacher
- Passed quizzes count toward your overall progress

**5. Classroom Progress & Communication**
- Your teacher can see which materials you've reviewed, which quizzes you've passed, and your overall classroom progress

**Switching Between Classrooms**
If you're enrolled in multiple classrooms, switch between them by selecting the classroom from the My Classrooms page. Each classroom has independent content and progress tracking.

Recommended first steps:

   - Enter your email and create a password
   - Or click "Login as Guest" to explore without creating an account

2. **Choose your learning path**
   - On your first visit, you'll be asked to choose between Basic Java or Enhanced Java

9. **Save your work**
   - Click "Save to My Work" on code snippets you want to keep
   - Access them anytime from the My Work page (📁 My Work)
   - Your work is saved to your account and syncs across devices

10. **Join a classroom (optional)**
    - If your teacher has created a classroom and given you a class code:
    - Go to My Classrooms page (🎓 My Classrooms) from the sidebar
    - Click "Join a Classroom" and enter the code
    - Access teacher-provided materials and classroom-specific quizzes

Throughout your learning:
- Use ☕ Ask AI frequently — it's powered by a comprehensive Java knowledge base and is ready to help
- Re-attempt quizzes on weak topics to improve your score
- Check your progress regularly to stay motivated

=== FOR TEACHERS: CLASSROOM MANAGEMENT ===

Teachers can create classrooms, upload course materials, generate quizzes, and monitor student progress. All teacher tools are accessible from the Teacher Dashboard.

**Accessing the Teacher Dashboard**
- Click 👑 Admin / Teacher Dashboard in the top-right menu (visible only to teacher accounts)
- Or navigate to /teacher-dashboard from the main platform

**Creating a New Classroom**
1. In the Teacher Dashboard, click "Create Classroom"
2. Enter a classroom name (e.g., "Java 101 - Day Class")
3. Add an optional description
4. Choose your course path (Basic Java or Enhanced Java)
5. Click "Create" — students can now join using the class code

**Sharing Your Classroom**
- After creating a classroom, you'll receive a unique class code
- Share this code with your students (e.g., via email, LMS, or handout)
- Students enter this code to join your classroom
- You can generate a new code anytime to invalidate old codes

**Uploading Course Materials**

Your uploaded materials become searchable by the AI tutor and appear in the classroom documents section.

To upload materials:
1. Open your classroom from the Teacher Dashboard
2. Click "Upload Materials" or "Add Files"
3. Select PDF or text files from your computer
4. Optionally organize them into sections/folders (e.g., "Week 1", "Chapter 3")
5. Click "Upload" — materials are indexed and ready for use

The platform automatically:
- Extracts text from PDFs
- Creates searchable chunks (short passages ~600 characters)
- Makes materials available for classroom-specific AI queries
- Tracks which students have read each material

**Managing Uploaded Materials**
- View all materials in the "Materials" section of your classroom
- Delete materials if needed (removes them from student access and AI search)
- Reorganize into sections/folders for clearer navigation
- Download original files if you need backup copies
- Track read progress — see which students have reviewed which materials

**Auto-Generating Quizzes from Materials**

The platform can automatically generate multiple-choice quizzes from your uploaded materials using AI:

1. In your classroom, navigate to "Quizzes"
2. Click "Generate Quiz from Materials"
3. Select which materials to quiz on
4. Choose number of questions (5, 10, or 15)
5. Select difficulty level (easy, medium, hard)
6. Click "Generate" — the system creates questions grounded in your materials
7. Review and edit the generated questions if needed
8. Click "Publish" to make the quiz available to students

**Grading & Analytics**
- View student quiz and test scores + which students passed/failed
- See which questions students struggled with most
- Track material read progress (% of students who've reviewed each document)
- Identify weak topics at the class level
- Export student work and scores for your gradebook

**Monitoring Student Progress**
1. Click "View Students" in your classroom
2. See each student's:
   - Materials reviewed (% completed)
   - Quizzes attempted and scores
   - Practical test scores
   - Overall classroom progress
3. Click on a student to see their full activity log

**Class Code & Access Control**
- Each classroom has a unique 6-8 digit class code
- Only students with the code can join
- You can regenerate the code anytime (old code stops working)

=== AI TUTOR SYSTEM ARCHITECTURE ===

The AI tutor is powered by a sophisticated Retrieval-Augmented Generation (RAG) system with multiple knowledge sources:

**Knowledge Sources:**
1. **Java Knowledge Base** — Over 2000 chunks covering Java syntax, OOP concepts, standard library, best practices (sourced from W3Schools, Oracle documentation, GeeksForGeeks, Think Java textbook)
2. **Platform Guide** — Documentation about CodeTutor itself (how to use features, navigate pages, etc.)
3. **Classroom Materials** — Your teacher's uploaded documents (PDFs, notes) specific to your course (if in a classroom)

**How the AI Routes Your Question:**
- If your question is about CodeTutor platform features (quiz, roadmap, classroom, playground, IDE, progress, joining a class) → searches Platform Guide
- If you're in a classroom and have "Classroom Mode" enabled → searches classroom materials first, then Java KB
- Otherwise → searches the Java Knowledge Base

=== TECHNICAL NOTES ===

**Technology Stack:**
- **Backend:** FastAPI (Python) with async support and PostgreSQL database
- **AI & Retrieval:** RAG using FAISS vectorstore for semantic search, powered by Qwen3-Max via HKBU GenAI Platform
- **Code Execution:** Remote Java compilation and execution via Paiza API (sandboxed)
- **Frontend:** React with Tailwind CSS, Monaco editor for code syntax highlighting
- **Authentication:** JWT tokens with 7-day expiry
- **Real-time Features:** WebSocket support for interactive terminal

**Performance & Limits:**
- Code execution timeout: ~30 seconds per submission
- Vector search: retrieves top 3 most relevant chunks (from pool of 15 candidates)
- Conversation history: auto-pruned after 10+ turns to maintain context efficiency
- Material upload: supports PDF and TXT formats

**Security:**
- Code execution is sandboxed (no direct file system or network access)
- JWT authentication required for all protected endpoints
- Role-based access control (student/teacher/admin)
- Classroom materials are scoped to enrolled students only

=== FREQUENTLY ASKED QUESTIONS ===

**Q: Can I use CodeTutor offline?**
A: No, CodeTutor requires an active internet connection. All code execution and AI tutor features run on our servers.

**Q: How do I join a classroom?**
A: Go to My Classrooms (🎓 My Classrooms) from the left sidebar, click "Join a Classroom", enter the class code your teacher provided, and click "Join". Codes are case-sensitive.

**Q: How does the quiz feature work on CodeTutor?**
A: Quizzes are a built-in assessment feature. Go to Exercises (📝) from the sidebar, select Java topics, choose 5/10/15 questions, and answer multiple-choice questions. A score of 70%+ is a pass. You can retake quizzes unlimited times.

**Q: What is the roadmap feature?**
A: The Roadmap is a visual map of all topics in your learning path. Basic Java has 52 subtopics across 12 groups; Enhanced Java has 26 subtopics across 8 groups. Complete topics in order by clicking "Mark as Complete" on each topic page.

**Q: How does the AI tutor know the answers?**
A: The AI searches a Java knowledge base (textbooks, documentation) and generates answers grounded in retrieved passages. The sources are shown so you can verify its answers.

**Q: Is there a limit to how many times I can take a quiz?**
A: No — you can attempt quizzes as many times as you want to improve your score.

**Q: What does "Weak Areas" mean?**
A: Weak Areas are topics where your average quiz/test score is below 70%. The platform recommends focusing on these to strengthen your overall Java foundation.

**Q: What if I can't join a classroom with the code provided?**
A: Codes are case-sensitive. Double-check you've entered it exactly. If the code is expired or invalid, ask your teacher for a new one.

**Q: Can I delete my account?**
A: Contact your platform administrator to delete your account. You can delete individual work items from "My Work" anytime.
